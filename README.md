## gtasa-reversed [![Build Status](https://github.com/gta-reversed/gta-reversed/actions/workflows/build.yml/badge.svg?branch=master)](https://github.com/gta-reversed/gta-reversed/actions?query=workflow%3ABuild)

A project to reverse Grand Theft Auto San Andreas completely, and to rewrite and document every function.

### Community
Please join our community Discord: [GTA Groupies](https://discord.gg/FG8XJ5Npqe) [The invite is permanent, feel free to share it!]

## About the project
Building this project will result in a DLL file that can be injected into GTA:SA using any ASI loader out there. After the DLL file has been injected, the ingame functions will be replaced by the reversed ones. The game will behave the same. Now if we make any changes to the reversed code, it will take effect in the game. The goal is to keep reversing until we have the entire game reversed to compile a standalone executable.

## Progress
The progress of the **registered hooks** is tracked in [ReversedClasses.md](docs/ReversedClasses.md) (generated by CI). That page only counts functions that already have a hook. Measured against the whole binary ([BinaryMap.md](docs/BinaryMap.md), Oct 2026), about **63% of the game's class methods** (~59% of their code) are reversed. RenderWare, D3DX and the CRT are excluded from that count, since they are called rather than reversed.
Since this project is done as a hobby, and worked on at irregular intervals, **there's no time estimate on when it'll be finished.**

## Build Instructions
#### 0. Requirements/Prerequisites
* [Visual Studio 2026](https://visualstudio.microsoft.com/en/downloads/)
* [Python](https://www.python.org/downloads/) >= 3.x (For Conan)
* [Conan](https://docs.conan.io/2/installation.html#install-with-pip-recommended) (>= 2.x)
* [CMake](https://cmake.org/download/) (>= 4.2.0)

#### 1. Install Python and Conan
* Install the [latest Python](https://www.python.org/downloads/) [When installing make sure to tick the "Add to PATH" checkbox!]
* Install Conan using `pip install conan` [You might need to reload the console if you've freshly installed Python.] (See [guide](https://docs.conan.io/2/installation.html#install-with-pip-recommended))
* If you are installing Conan for the first time, also run `conan profile detect`

#### 2. Setting up VS
0) Run the setup script with `python setup.py` - It defaults to the `conan/profiles/windows-msvc.txt` profile (x86 Debug). If you want a different configuration you have to pass Conan settings/options to the script (ex.: `python setup.py -s build_type=Release`) or use custom profiles (`-p`). Build options are listed in [Architecture.md](docs/Architecture.md#2-build).
1) Open the folder with VS's native CMake integration (Right click -> "Open in Visual Studio") - The `.sln` generated by CMake should (in theory) work as well, but the CMake integration works somewhat better.
2) If you'd just like to build use `python setup.py --build`, or `cmake --build build --config Debug --target gta_reversed` after setup (Or if you're experienced with `conan`, you can use it directly as well). The output goes to `bin/<Debug|Release>/`.

#### 3. Set up the game and ASI
0. GTA SA ***Compact exe***: Our code requires you to use this exe, otherwise you will experience random crashes. **You must own the original game and assets for this to work.**

> [!IMPORTANT]
> GTA SA ***Compact exe*** is not the same as ***1.0 US exe***, so check that your executable is exactly `5'189'632 bytes` (4.94 MiB).

1. To install all the necessary files (after building the project!), run `contrib/install.py` with **__administrator privileges__** [Necessary to create symlinks on Windows] in the root directory. It unpacks `contrib/plugins.zip` into the game folder and symlinks the `.asi`/`.pdb` of the configuration you pick (debug by default) into `scripts/`.
Alternatively, you can install them by yourself:
    * [ASI Loader](https://gtaforums.com/topic/523982-relopensrc-silents-asi-loader/)
    * Mouse Fix (**dinput8.dll**)

    Both are in [`contrib/plugins.zip`](contrib/plugins.zip), together with `scripts/gta-reversed.ini`.

### Other plugins
Using other (than the ones we've tested) plugins is strongly discouraged and we provide __**no support**__.

## Contributing

### Coding/Contributing Guidelines
Before you start writing code, please make sure to read the [coding guidelines](docs/CodingGuidelines.md) for this project. These docs are also useful:
* [Architecture](docs/Architecture.md): how the DLL is built and injected, how hooks work, where things live
* [Reversing rules](docs/ReversingRules.md): the rules every reversed function must follow, with how to check each one
* [Reversing guide](docs/ReversingGuide.md): how to reverse a function and validate it against the original binary (static checks and differential tests)
* [Hook registration](docs/HookRegistration.md): how to register reversed functions (`InjectHooks`, `RH_Scoped*` macros)
* [Script command reversing](docs/ScriptCommandReversing.md): how to implement script commands
* [Binary map](docs/BinaryMap.md) and [subsystem docs](docs/subsystems/): layout of the executable and how each game system works
* [Glossary](docs/Glossary.md): project, compiler, engine and script terms

Consider these points before opening a PR:

* Follow the coding guidelines, it exists for a reason.
* Try to focus your changes onto single subject, do not create PRs that cover many things at once. This is because it's hard to properly test and review such PRs.
* If you intend to add non-vanilla features please first consult with us, so you don't waste your time.

### Debugging
0) Make sure the latest DLL is in the `scripts` folder of your GTASA installation - Skip this step if you've used `contrib/install.py` (As it symlinks the configuration you picked)
1) Launch the game
2) Attach using the [ReAttach plugin](https://marketplace.visualstudio.com/items?itemName=ErlandR.ReAttach) to make your life easier (or pass `--debug` to make the game wait for a debugger before the hooks are installed)

The in-game debug menu (**F7**) lets you switch hooks between our code and the original (Settings → Hooks). Logs are written to `scripts/logs/log.log`.
